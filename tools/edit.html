CODE 글 수정 도구

이미 올라간 갤러리 사진이나 로그 글을 골라서 내용을 고치거나 통째로 지울 수 있어요. 잠긴 로그 글은 비밀번호를 넣어야 내용을 불러올 수 있어요.

GitHub 토큰은 어떻게 만들어요? (처음 한 번만)
  1. GitHub 로그인 후 github.com/settings/personal-access-tokens/new 접속
  2. Repository access → Only select repositories 선택 → s2ndrome/code 선택
  3. Permissions → Contents → Read and write로 설정
  4. Generate token → 생성된 토큰(github_pat_...) 복사
  5. 아래 칸에 붙여넣기 — 업로드 도구랑 같은 토큰 써도 돼요

🔒 이 글은 잠겨 있어요. 비밀번호를 넣고 불러와야 내용을 볼 수 있어요.
